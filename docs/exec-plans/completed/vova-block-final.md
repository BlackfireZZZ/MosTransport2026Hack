## Границы доказанного

Данные остаются демонстрационными; нет подключённого потока реальных наблюдений,
измеренного SLA или подтверждённого качества модели. Legacy cutoff не выдаётся за
реальное наблюдение. TASK024 не завершён вне этого блока: интервалы показаны без
утверждения о калибровке. Отсутствующие края OSM не рисуются реальными рельсами;
синтетические координаты явно отделены от подтверждённого сопоставления.

API не подтверждает единицы/источник/область вместимости. Поэтому проценты загрузки,
линия вместимости и необоснованный сценарный расчёт не показываются. Сценарию также
нужна привязка к видимому run/window. Это явно описанная недоступность, а не нулевой
результат. Фоновая карта в browser-проверках работает в контролируемом offline режиме;
проверены деградация, повторная загрузка и доступные значения без WebGL.

Зависимости и lock-файлы проекта не менялись. ML, исходная миграция и authored
contracts не изменялись; OpenAPI и frontend types регенерированы для API дополнений.
